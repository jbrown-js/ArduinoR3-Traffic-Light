# 🚦 ArduinoR3-Traffic-Light

A simple traffic light simulation built using an **Arduino Uno R3** and LEDs. This project replicates the basic sequence of a real-world traffic light, using Arduino programming to control the LEDs.

## 📸 About the Project

This project was created to explore the basics of Arduino and it was my first electronics project! it Features, LED control, and embedded programming. It simulates a traffic light system by switching LEDs through a predefined sequence.

## 🛠️ Hardware Used

- Arduino Uno R3
- LEDs (Red, Yellow, and Green)
- Current-limiting resistors (220 ohms)
- Breadboard
- Jumper wires
- USB cable for programming and power


## ⚙️ How It Works

The Arduino controls each LED to simulate a traffic light cycle:

1. 🔴 **Red** — Stop
2. 🟢 **Green** — Go
3. 🟡 **Yellow** — Prepare to stop

The LEDs turn on and off in sequence, with timed delays between each state.

## 💻 Software

- [Arduino IDE](https://www.arduino.cc/en/software)
- Arduino programming language (C/C++)

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the Arduino sketch (`.ino` file) in the Arduino IDE.
3. Connect your Arduino Uno R3 to your computer via USB.
4. Select **Arduino Uno** as the board and choose the correct port.
5. Upload the sketch to your Arduino.
6. Watch your traffic light simulation run!
